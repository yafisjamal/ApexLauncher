# Apex Launcher

Apex Launcher is a modern Minecraft launcher focused on simplicity, performance, and a clean user experience.

Built to provide a smoother way to launch Minecraft, Apex Launcher combines a minimal interface with useful features while maintaining a lightweight design.

## Features

- Lightweight and optimized performance
- Minecraft account management
- Minecraft version selector
- Mod support
- Automatic updates
- Custom settings panel
- Modern user interface
